# Isream

Launcher de Minecraft Java para Windows y Linux.

**[Descargar la última versión](https://github.com/rekikaiser2/isream-releases/releases/latest)**

- **Windows:** instala el archivo `x64-setup.exe` sobre la versión anterior.
- **Linux:** usa `AppImage` para recibir actualizaciones desde la aplicación. También se ofrece el paquete `.deb`.
- Desde la versión **0.4.40**, Isream avisa cuando hay una nueva versión y permite actualizar desde su barra superior.

Este repositorio distribuye instaladores y actualizaciones con firma criptográfica. El código fuente se mantiene en un repositorio privado.
